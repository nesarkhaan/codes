# Mission 3: SeniorLearn Course Enrollment (Lists)

**The Goal:** You are building the backend for a community learning platform. You need to manage a dynamic roster of students for a specific course using `List<T>`.

**Your Tasks:**
1. Review the `Student` class (already completed).
2. Complete the `Course` class methods:
   - `Enroll(Student newStudent)`: Add the student to the list.
   - `GetClassSize()`: Return the total number of students currently enrolled.
   - `DropOut(string studentName)`: Search the list for a student with this name. If found, remove them and return `true`. If they aren't in the class, return `false`.
   - `GetOldestStudent()`: Loop through the list and return the `Student` object who has the highest age. Return `null` if the class is empty.
